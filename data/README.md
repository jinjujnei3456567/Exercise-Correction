# 哮天犬微调数据集

## 格式说明

每行一条JSON，格式如下：

```json
{
  "instruction": "问题",
  "input": "",
  "output": "回答"
}
```

## 示例

```json
{"instruction": "你是谁？", "input": "", "output": "我是哮天犬，你的运动防伤AI顾问。"}
{"instruction": "深蹲膝盖疼怎么办？", "input": "", "output": "建议先检查膝盖是否内扣，下蹲深度不要超过90度..."}
```

## 怎么扩充数据集

1. 收集运动防伤常见问题（可以从知乎、小红书、健身论坛找）
2. 写好专业回答（参考运动康复指南）
3. 整理成上面的JSON格式
4. 越多越好，至少几百条效果才明显

## 推荐数据来源

- PubMed 运动康复文献
- 运动康复师公众号文章
- 健身论坛常见问题
- 临床指南
